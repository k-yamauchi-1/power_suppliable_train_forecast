第1条（本規約について）

本利用規約（以下「本規約」）は、個人開発者である運営者が提供するモバイルアプリケーション「ロマンスカー充電コンセント予報」（以下「本アプリ」）の利用に関する条件を定めるものです。

第2条（本アプリの概要）

本アプリは、小田急ロマンスカーの列車ごとの充電設備（コンセント）の有無を予測し、情報を提供するアプリです。

本アプリは、小田急電鉄株式会社およびその関連企業（以下「公式」）とは一切関係のない、個人による非公式のアプリです。

ロマンスカー充電コンセント予報 プライバシーポリシー

最終更新日: 2026年7月5日

はじめに

運営者は、モバイルアプリケーション「ロマンスカー充電コンセント予報」（以下「本アプリ」）における利用者のプライバシーを尊重し、個人情報の保護に努めます。本プライバシーポリシーでは、本アプリにおける情報の取り扱いについて説明いたします。

1. 収集する情報

1.1 自動的に生成される情報

本アプリは、サービスの提供にあたり Firebase Authentication の匿名認証を使用します。これにより、以下の情報が自動的に生成されます。

  • 匿名ユーザーID: アプリの利用時に Firebase により自動生成される匿名の識別子です。氏名、メールアドレス、電話番号等の個人を特定しうる情報とは紐づきません。

1.2 端末にのみ保存される情報

本アプリは、以下の情報を端末内のローカルストレージ（SharedPreferences）にのみ保存します。これらの情報は外部サーバーに送信されません。

  • 検索条件の保存データ（出発駅、方面、降車駅、時刻等の検索設定）
  • 利用規約への同意状態

1.3 収集しない情報

本アプリは、以下の情報を一切収集しません。

  • 氏名、住所、電話番号、メールアドレス等の個人情報
  • 連絡先情報

以下の情報は現時点では収集していません。将来的な機能追加により収集が必要になった場合は、本プライバシーポリシーを改定し、「8. プライバシーポリシーの変更」に定める方法にて予めお知らせします。収集の開始は、その告知後に利用者が同意された場合に限ります。

  • 位置情報
  • 写真、動画等のメディアファイル
  • デバイスの識別情報（広告ID等）
  • 利用状況に関するアナリティクスデータ

2. 情報の利用目的

自動的に生成される匿名ユーザーIDは、以下の目的のみに利用されます。

  • Cloud Firestore からの、充電できるロマンスカー予報データ読取アクセスの認証

3. 第三者への情報提供

運営者は、利用者の情報を第三者に提供、販売、または共有いたしません。ただし、法令に基づく場合はこの限りではありません。

4. 利用している外部サービス

本アプリは、以下の外部サービスを利用しています。

サービス提供元利用目的プライバシーポリシー
Firebase Authentication Google LLC 匿名認証 Firebase のプライバシーとセキュリティ
Cloud Firestore Google LLC ロマンスカー充電コンセント予報データの取得 同上
Google Cloud Storage Google LLC 時刻表マスタデータの取得 Google プライバシーポリシー

これらのサービスのデータ取り扱いについては、各サービスのプライバシーポリシーをご確認ください。

5. データの保護

  • 外部サーバーとの通信はすべて暗号化（HTTPS/TLS）により保護されています。
  • ローカルに保存されるデータは、端末のセキュリティ機能により保護されます。

6. お子様のプライバシー

本アプリは年齢制限を設けておりませんが、個人情報を収集しないため、お子様のプライバシーに特別なリスクはありません。

7. データの削除

  • ローカルに保存されたデータは、アプリをアンインストールすることで完全に削除されます。
  • Firebase Authentication により生成された匿名ユーザーIDは、アプリのアンインストール後に自動的に無効化されます。

8. プライバシーポリシーの変更

運営者は、必要に応じて本プライバシーポリシーを変更する場合があります。重要な変更がある場合は、本ページへの掲示および X（@pwrSupplyTrnApp）への投稿にてお知らせいたします。変更後のプライバシーポリシーは、掲示した時点で効力を生じるものとします。
