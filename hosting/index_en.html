Romancecar Power Supply Forecast Privacy Policy

Last Updated: August 2, 2026

Introduction

The operator respects user privacy in the mobile application "Romancecar Power Supply Forecast" (hereinafter "App") and strives to protect personal information. This Privacy Policy explains the handling of information in this App.

1. Information Collected

1.1 Automatically Generated Information

This App uses anonymous authentication from Firebase Authentication to provide services. As a result, the following information is automatically generated:

  • Anonymous User ID: An anonymous identifier automatically generated by Firebase when using the app. It is not linked to personally identifiable information such as name, email address, or phone number.

1.2 Information Collected for App Stability Improvement

This App utilizes Firebase Crashlytics to improve app quality and to detect and fix bugs early. As a result, the following information is automatically collected:

  • Crash and Error Information: Stack traces (technical logs indicating where an error occurred) when the app terminates abnormally or experiences an error.
  • Device Information: Device environment details required to identify crash causes, such as OS type and version, device model name, and available memory.
  • Crashlytics Installation ID: An anonymous identifier automatically generated by Firebase Crashlytics, used to measure crash counts. It is not linked to personally identifiable information.

This information does not identify individuals and is used solely for the purpose of improving app stability.

1.3 Information Stored Only on Device

This App stores the following information only in local storage (SharedPreferences) on the device. This information is not sent to external servers:

  • Saved search conditions data (departure station, direction, arrival station, time settings, etc.)
  • Consent status for Terms of Service

1.4 Information Not Collected

This App does not collect any of the following information:

  • Personal information such as name, address, phone number, or email address
  • Contact information

The following information is not collected at present. If collection becomes necessary due to future feature additions, this Privacy Policy will be revised and announced in advance according to "8. Changes to Privacy Policy". Collection will begin only if the user agrees after such notification.

  • Location information
  • Media files such as photos or videos
  • Device advertising ID
  • Analytics data regarding usage status (behavioral data such as screen transitions and tap operations)

2. Purpose of Use of Information

The collected information is used solely for the following purposes:

  • Anonymous User ID: Authentication for reading power supply forecast data for Romancecar from Cloud Firestore
  • Crash and Error Information & Device Information: Detection, root cause identification, and fixing of app bugs and errors (via Firebase Crashlytics)
